这是 Unity 引擎中 **Canvas（画布）** 组件的设置面板。下面逐段解释每个参数的含义，并附上 PC 单机游戏的推荐设置。

------

### Canvas 参数详解

#### 基础设置

| 参数                      | 含义                                                         |
| ------------------------- | ------------------------------------------------------------ |
| **Theme Style Sheet**     | UI 主题样式表，用于统一管理 UI 的视觉风格（颜色、字体等）。  |
| **Panel Text Settings**   | 面板文本设置，控制文本的默认渲染属性（如抗锯齿、字距等）。   |
| **Binding Console Logs**  | 绑定控制台日志输出级别，可选 All logs / Warnings / Errors 等。 |
| **Render Mode**           | 渲染模式，决定 UI 如何渲染到屏幕上（见下方详解）。           |
| **Target Texture**        | 当 Render Mode 为 World Space 或 Camera 时，可将 UI 渲染到 Render Texture 上。 |
| **Target Display**        | 目标显示器，多屏时使用（Display 1、Display 2...）。          |
| **Force Gamma Rendering** | 强制 Gamma 色彩空间渲染，通常不勾选。                        |
| **Sort Order**            | 渲染层级排序值，数值越大越靠前（Z轴层级）。                  |
| **Scale Mode**            | 缩放模式，决定 UI 如何适配不同分辨率。                       |

#### Render Mode（渲染模式）三种选择

- **Screen Space - Overlay**：UI 直接覆盖在屏幕最上层，不受相机影响，性能最好。
- **Screen Space - Camera**：UI 由指定相机渲染，可配合相机做后处理效果。
- **World Space**：UI 作为 3D 世界中的物体存在（如游戏内电脑屏幕、血条）。

#### Scale Mode Parameters（缩放模式参数）

| 参数                     | 含义                                               |
| ------------------------ | -------------------------------------------------- |
| **Screen Match Mode**    | 屏幕匹配模式，决定 UI 适配分辨率的策略。           |
| **Reference Resolution** | 参考分辨率，UI 设计时的基准分辨率（宽 X / 高 Y）。 |

#### Screen Match Mode（屏幕匹配模式）三种选择

- **Match Width Or Height**：根据滑块值在"匹配宽度"和"匹配高度"之间插值（0=匹配宽，1=匹配高）。
- **Expand**：Canvas 会扩大以容纳所有 UI，可能出现黑边。
- **Shrink**：Canvas 会缩小以适应屏幕，可能裁剪边缘。

| 参数                                 | 含义                                                         |
| ------------------------------------ | ------------------------------------------------------------ |
| **Match（滑块）**                    | 0 表示完全按宽度适配，1 表示完全按高度适配，0.5 表示宽高取中间值。 |
| **Reference Sprite Pixels per Unit** | 参考精灵的每单位像素数，通常保持 100。                       |

#### Dynamic Atlas Settings（动态图集设置）

| 参数                     | 含义                                                         |
| ------------------------ | ------------------------------------------------------------ |
| **Min Atlas Size**       | 动态图集最小尺寸（纹理像素），默认 64。                      |
| **Max Atlas Size**       | 动态图集最大尺寸，默认 4096。图集越大能打包的 UI 贴图越多。  |
| **Max Sub-Texture Size** | 子纹理最大尺寸，默认 64。                                    |
| **Active Filters**       | 激活的图集过滤规则，Everything 表示所有 UI 元素都参与图集打包。 |

#### Clear Settings（清除设置）

| 参数                    | 含义                                    |
| ----------------------- | --------------------------------------- |
| **Clear Color**         | 清除颜色，UI 渲染前清空屏幕用的背景色。 |
| **Color Clear Value**   | 颜色清除值（RGBA），默认黑色半透明。    |
| **Clear Depth Stencil** | 是否清除深度模板缓冲，通常勾选。        |

#### Buffer Management（缓冲区管理）

| 参数                      | 含义                                                         |
| ------------------------- | ------------------------------------------------------------ |
| **Vertex Budget**         | 顶点预算，控制每帧 UI 顶点更新的上限，0 表示无限制。         |
| **Extra Vertex Channels** | 额外顶点通道，用于自定义着色器传递数据，通常选 None。        |
| **Texture Slot Count**    | 纹理槽位数，决定 UI 材质可同时使用的纹理数量，Eight 为默认值。 |

------

### 🎮 PC 单机游戏推荐设置

> 假设目标分辨率为 **1920×1080**，支持窗口化和全屏切换。

```
Render Mode              → Screen Space - Overlay
Target Display           → Display 1
Sort Order               → 0（主UI层），弹窗可设为 1~10
Scale Mode               → Scale With Screen Size
  Screen Match Mode      → Match Width Or Height
  Reference Resolution   → X: 1920, Y: 1080
  Match 滑块             → 0（优先匹配宽度，适合横屏PC游戏）
  Reference PPU          → 100
Dynamic Atlas:
  Min Atlas Size         → 256
  Max Atlas Size         → 4096
  Active Filters         → Everything
Clear Depth Stencil      → ✓（勾选）
Vertex Budget            → 0
Extra Vertex Channels    → None
Texture Slot Count       → Eight
```

#### 补充建议

- **多分辨率支持**：如果你的游戏需要支持 21:9 超宽屏，建议将 Match 滑块调到 **0.3~0.5**，让高度也参与适配。
- **弹窗/二级UI**：复制一份 Canvas，Render Mode 保持不变，Sort Order 设为更高值即可实现层级覆盖。
- **3D世界内UI**（如角色头顶血条、场景内公告牌）：单独建一个 Canvas，Render Mode 选 **World Space**，调整 Transform 放到场景中。
- **性能优化**：静态 UI（不频繁变化的）可以开启 **Canvas 静态批处理**，动态 UI（频繁更新的）拆分到独立 Canvas 避免整体重建。
