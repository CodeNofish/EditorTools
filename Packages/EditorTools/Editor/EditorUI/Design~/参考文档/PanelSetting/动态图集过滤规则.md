在 Unity 的 UI Toolkit 中，`Panel Settings`（面板设置）中的 **Active Filters**（活跃过滤器）是用于**动态图集（Dynamic Atlas）**的配置项。

简单来说，它设置的是：**哪些纹理（图片）应该被排除在动态图集之外，不参与到运行时的自动合批中。**

### 1. 为什么需要这个设置？

UI Toolkit 在运行时会启用“动态图集”功能，自动把 UI 中使用的零散小图片合并成一张大纹理，从而降低 Draw Call、提升渲染性能。

但是，并不是所有的图片都适合被打包进图集。例如：

- 某些图片太大了，放进去会浪费图集空间。
- 某些图片在代码运行时需要被修改（Read/Write），如果打包进图集，修改时会破坏图集里其他图片。
- 某些图片格式太特殊（如 HDR 纹理），强行打包会导致颜色失真。

**Active Filters 就是用来精准排除这些不适合打包的图片的规则。**

------

### 2. 可选的过滤规则（Filter）有哪些？

在 `Panel Settings` 的 `Dynamic Atlas Settings > Active Filters` 下拉菜单中，你可以勾选以下一个或多个过滤规则：

- **Readability（可读性过滤）**：
  - **作用**：排除在导入设置中开启了 **Read/Write Enabled（可读/写）** 的纹理。
  - **原因**：运行时脚本如果修改了这种可读写纹理，由于它被打包在图集中，会导致整个图集中其他使用该纹理的 UI 元素显示异常。
- **Size（尺寸过滤）**：
  - **作用**：排除尺寸超过了动态图集设置中 **Max Sub Texture Size（最大子纹理尺寸）** 的超大图片。
  - **原因**：超大图片单独渲染更合适，强行塞入图集会占用过大空间，降低图集利用率。
- **Format（格式过滤）**：
  - **作用**：排除那些因为格式原因（比如每通道超过 8 位的高精度格式、HDR 纹理等），加入图集会导致精度丢失或被截断的纹理。
- **None（无过滤）**：
  - **作用**：不进行任何过滤，尝试将所有符合条件的纹理都打包进动态图集。

------

### 3. 实际开发建议

- **默认推荐**：通常建议**同时勾选 `Readability`、`Size` 和 `Format`**（即使用 `Default` 默认过滤）。这样可以安全地把常规 UI 小图标、背景切片打包，而把需要运行时修改的图（如动态生成的头像）和大图排除在外。
- **如果你的 UI 出现了贴图重叠、颜色错乱**：可以先检查是否误关了 `Readability` 过滤，或者代码中修改了本该打包进图集的纹理。
