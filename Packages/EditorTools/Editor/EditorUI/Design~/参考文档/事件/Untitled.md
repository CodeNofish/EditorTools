# **使用操纵器捕获指针**

捕获指针以确保元素能够接收所有后续的指针事件。

在处理指针输入时，您可能希望控件能够捕获指针。当某个可视元素捕获了指针后，无论指针是否悬停在该可视元素上方，Unity 都会将所有与该指针相关的事件发送给该可视元素。例如，如果您创建了一个接收拖拽事件并捕获了指针的控件，那么无论指针位于何处，该控件都会持续接收拖拽事件。

`Manipulator` 类提供了一种便捷的方式来捕获指针。`Manipulator` 类是所有操纵器的基类。操纵器是一种处理指针输入并将事件发送给可视元素的类。例如，`Clickable` 类就是一种操纵器，当用户点击可视元素时，它会发送 `PointerDownEvent`。在触发 `PointerDownEvent` 之后，某些元素必须捕获指针位置，以确保即使光标不再悬停在该元素上方，它也能接收所有后续的指针事件。例如，当您点击按钮、滑块或滚动条时就会出现这种情况。

要捕获指针，请调用 `PointerCaptureHelper.CapturePointer`。

要释放指针，请调用 `PointerCaptureHelper.ReleasePointer`。如果在调用 `CapturePointer()` 时已有其他元素正在捕获指针，则该原有元素会收到 `PointerCaptureOutEvent` 事件并失去捕获状态。

在任何时刻，应用程序中只能有一个元素拥有捕获状态。当某个元素处于捕获状态时，除鼠标滚轮事件外，它将成为所有后续指针事件的目标。这仅适用于那些尚未设定目标且依赖分发流程来确定目标的指针事件。

更多信息，请参阅“捕获事件”。
