# Synthesize and send events 合成并发送事件

本文通过示例介绍如何合成并发送事件。

在合成并发送自定义事件之前，先了解 UI Toolkit 事件系统是如何分配和发送操作系统事件的。

UI Toolkit 通过面板（panel）向视觉元素发送事件。如果某个事件没有目标（target），它会被发送给面板的根元素。要形成一条传播路径，元素必须具有目标，并且发送方需要事先设置好该目标。某些事件类型不需要目标，例如键盘事件会发送给当前获得焦点的元素，指针事件会发送给指针下方的元素。

事件系统使用一个事件对象池，以避免重复分配事件对象。

要合成并发送你自己的事件，步骤如下：

1. 从事件池中获取一个事件对象。
2. 填写事件的各个属性。
3. 用 `using` 块包裹该事件，以确保它被归还到事件池中。
4. 把事件传给 `panel.visualTree.SendEvent()`。

你可以发送操作系统事件，例如键盘事件和指针事件。做法是使用 `UnityEngine.Event` 来初始化 UI Toolkit 事件。

下面的示例演示了如何合成并发送事件：

```csharp
void SynthesizeAndSendKeyDownEvent(IPanel panel, KeyCode code,
     char character = '\0', EventModifiers modifiers = EventModifiers.None)
{
    // 创建一个 UnityEngine.Event 用于承载初始化数据。
    var evt = new Event() {
        type = EventType.KeyDownEvent,
        keyCode = code,
        character = character,
        modifiers = modifiers
    };

    using (KeyDownEvent keyDownEvent = KeyDownEvent.GetPooled(evt))
    {
        panel.visualTree.SendEvent(keyDownEvent);
    }
}
```

> **重要** 不要发送那些来自操作系统之外、或在 `UnityEngine.Event` 类型中不存在的事件。UI Toolkit 会因内部状态变化而发送某些事件，外部进程不得发送这些事件。例如，如果你发送 `PointerCaptureEvent`，视觉元素会认为该事件所需的基础条件已经满足，从而不再自行设置指针捕获。这可能破坏视觉元素的内部配置，并导致未定义的行为。
