## 内容摘要

本文介绍 UI Toolkit 中的**操纵器（manipulator）**：一种把事件处理逻辑从 UI 代码中剥离出来的状态机，它负责存储、注册和注销事件回调。文中给出支持的操纵器类层次表，并通过「拖拽（ExampleDragger）」「缩放（ExampleResizer）」两个完整示例演示如何自定义操纵器、挂载与移除。

------

## 操纵器（Manipulators）

使用操纵器来处理事件。

为了把事件逻辑与 UI 代码分离开来，可以使用操纵器（manipulator）来处理事件。操纵器是处理用户与 UI 元素交互的状态机，负责存储、注册和注销事件回调。操纵器简化了设置用户交互的过程，使你不必逐一处理每个回调。要处理事件，请使用或继承 UI Toolkit 支持的某种操纵器。

创建并使用操纵器的步骤如下：

1. 定义一个专门的类，继承 UI Toolkit 支持的某个操纵器类。这个类把事件处理逻辑封装起来，专门用于管理你所指定的那种用户交互。
2. 在该类中实现响应相关交互的方法，例如鼠标点击或拖拽。这些方法捕获并处理所需的信息，以执行期望的行为。
3. 设计完操纵器类后，将其实例化并附加到目标 UI 元素上。完成附加后，操纵器就能拦截并管理指定的事件，协调用户交互，同时与你的 UI 代码保持清晰的分离。

### 支持的操纵器

下表列出了支持的操纵器类：

| 操纵器                        | 继承自             | 说明                                                         |
| ----------------------------- | ------------------ | ------------------------------------------------------------ |
| Manipulator                   | ——                 | 所有内置操纵器的基类。                                       |
| KeyboardNavigationManipulator | Manipulator        | 负责把设备专属的输入事件转换为更高层的键盘导航操作。         |
| MouseManipulator              | Manipulator        | 处理鼠标输入。拥有一个激活过滤器（activation filter）列表。  |
| ContextualMenuManipulator     | MouseManipulator   | 当用户点击鼠标右键或按下键盘上的菜单键时，显示上下文菜单。   |
| PointerManipulator            | MouseManipulator   | 处理指针输入。拥有一个激活过滤器列表。                       |
| Clickable                     | PointerManipulator | 跟踪元素上的鼠标事件，识别点击的发生时机——所谓点击，是指在同一条元素上既按下又松开指针。 |

### 示例

下面的示例演示如何使用操纵器来处理事件。这些示例完成了以下事项：

- 从 PointerManipulator 类继承操纵器，该类负责处理鼠标输入。
- 使用 `activators`（激活器）列表来指定触发操纵器激活的条件。例如，要在用户点击鼠标左键时激活操纵器，就往 `activators` 列表中添加一个 `ManipulatorActivationFilter`，并将其 `button` 字段设为 `MouseButton.LeftMouse`。
- 使用 `target` 属性来访问操纵器所附加的那个元素。
- 重写 `RegisterCallbacksOnTarget` 和 `UnregisterCallbacksFromTarget` 方法来注册和注销事件回调。



#### 创建 ExampleDragger 操纵器

下面的示例创建一个操纵器，让你可以在点击并拖动某个元素时移动它：

```csharp
using UnityEngine;
using UnityEngine.UIElements;

public class ExampleDragger : PointerManipulator
{
    private Vector3 m_Start;
    protected bool m_Active;
    private int m_PointerId;
    private Vector2 m_StartSize;

    public ExampleDragger()
    {
        m_PointerId = -1;
        activators.Add(new ManipulatorActivationFilter { button = MouseButton.LeftMouse });
        m_Active = false;
    }

    protected override void RegisterCallbacksOnTarget()
    {
        target.RegisterCallback<PointerDownEvent>(OnPointerDown);
        target.RegisterCallback<PointerMoveEvent>(OnPointerMove);
        target.RegisterCallback<PointerUpEvent>(OnPointerUp);
    }

    protected override void UnregisterCallbacksFromTarget()
    {
        target.UnregisterCallback<PointerDownEvent>(OnPointerDown);
        target.UnregisterCallback<PointerMoveEvent>(OnPointerMove);
        target.UnregisterCallback<PointerUpEvent>(OnPointerUp);
    }

    protected void OnPointerDown(PointerDownEvent e)
    {
        if (m_Active)
        {
            e.StopImmediatePropagation();
            return;
        }

        if (CanStartManipulation(e))
        {
            m_Start = e.localPosition;
            m_PointerId = e.pointerId;

            m_Active = true;
            target.CapturePointer(m_PointerId);
            e.StopPropagation();
        }
    }

    protected void OnPointerMove(PointerMoveEvent e)
    {
        if (!m_Active || !target.HasPointerCapture(m_PointerId))
            return;

        Vector2 diff = e.localPosition - m_Start;

        target.style.top = target.layout.y + diff.y;
        target.style.left = target.layout.x + diff.x;

        e.StopPropagation();
    }

    protected void OnPointerUp(PointerUpEvent e)
    {
        if (!m_Active || !target.HasPointerCapture(m_PointerId) || !CanStopManipulation(e))
            return;

        m_Active = false;
        target.ReleaseMouse();
        e.StopPropagation();
    }
}
```



#### 创建 ExampleResizer 操纵器

下面的示例创建一个操纵器，让你在拖动某个元素时改变它的大小：

```csharp
using UnityEngine;
using UnityEngine.UIElements;

public class ExampleResizer : PointerManipulator
{
    private Vector3 m_Start;
    protected bool m_Active;
    private int m_PointerId;
    private Vector2 m_StartSize;
    public ExampleResizer()
    {
        m_PointerId = -1;
        activators.Add(new ManipulatorActivationFilter { button = MouseButton.LeftMouse });
        m_Active = false;
    }

    protected override void RegisterCallbacksOnTarget()
    {
        target.RegisterCallback<PointerDownEvent>(OnPointerDown);
        target.RegisterCallback<PointerMoveEvent>(OnPointerMove);
        target.RegisterCallback<PointerUpEvent>(OnPointerUp);
    }

    protected override void UnregisterCallbacksFromTarget()
    {
        target.UnregisterCallback<PointerDownEvent>(OnPointerDown);
        target.UnregisterCallback<PointerMoveEvent>(OnPointerMove);
        target.UnregisterCallback<PointerUpEvent>(OnPointerUp);
    }

    protected void OnPointerDown(PointerDownEvent e)
    {
        if (m_Active)
        {
            e.StopImmediatePropagation();
            return;
        }

        if (CanStartManipulation(e))
        {
            m_Start = e.localPosition;
            m_StartSize = target.layout.size;
            m_PointerId = e.pointerId;
            m_Active = true;
            target.CapturePointer(m_PointerId);
            e.StopPropagation();
        }
    }

    protected void OnPointerMove(PointerMoveEvent e)
    {
        if (!m_Active || !target.HasPointerCapture(m_PointerId))
            return;

        Vector2 diff = e.localPosition - m_Start;

        target.style.height = m_StartSize.y + diff.y;
        target.style.width = m_StartSize.x + diff.x;

        e.StopPropagation();
    }

    protected void OnPointerUp(PointerUpEvent e)
    {
        if (!m_Active || !target.HasPointerCapture(m_PointerId) || !CanStopManipulation(e))
            return;

        m_Active = false;
        target.ReleasePointer(m_PointerId);
        m_PointerId = -1;
        e.StopPropagation();
    }
}
```



#### 添加或移除操纵器

要向某个元素添加操纵器，使用 `AddManipulator` 方法；要从某个元素移除操纵器，使用 `RemoveManipulator` 方法。

下面的示例向一个 `VisualElement` 添加并移除 `ExampleDragger`：

```csharp
// 创建一个 VisualElement。
var myElement = new VisualElement();
var dragger = new ExampleDragger();

// 向 VisualElement 添加操纵器。
myElement.AddManipulator(dragger);

// 从 VisualElement 移除操纵器。
myElement.RemoveManipulator(dragger);
```

下面的示例向一个 `VisualElement` 添加 `ExampleResizer`：

```csharp
var box = new VisualElement()
{
    style =
    {
        left = 100,
        top = 100,
        width = 100,
        height = 100,
        backgroundColor = Color.red
    },
    pickingMode = PickingMode.Position,
};

box.AddManipulator(new ExampleResizer());
```

### 关键术语注释

1. **manipulator** → 操纵器：UI Toolkit 中封装事件处理逻辑、独立于 UI 代码的状态机对象。
2. **activation filter / activators** → 激活过滤器／激活器列表：决定操纵器在何种输入条件下被激活（如限定左键）。保留类名 `ManipulatorActivationFilter`。
3. **target** → 目标元素：操纵器所附加、并对其拦截事件的那个视觉元素。
4. **CapturePointer / HasPointerCapture / ReleasePointer** → 捕获指针／是否已捕获指针／释放指针：拖拽、缩放期间为保证指针事件持续送达目标元素而做的指针捕获操作。
5. **StopPropagation / StopImmediatePropagation** → 停止（事件）冒泡／立即停止冒泡：阻止事件继续沿传播路径传递。
