## UI Toolkit 中的焦点系统

理解元素的焦点顺序。

UI Toolkit 中的焦点系统负责管理哪个元素当前接收键盘或导航输入。它控制焦点如何在元素之间移动，并在元素获得或失去焦点时触发焦点事件。

### 核心概念

焦点系统由以下几个关键部分组成：

- **focusable**：这个元素能否接收焦点？
- **canGrabFocus**：这个元素当前是否具备被聚焦的条件（可见、已启用等）？
- **tabIndex**：导航时各元素被聚焦的次序。
- **delegatesFocus**：若为 true，则把焦点传递给某个合适的子元素。
- **Focus()**：请求让某个元素获得焦点的方法。
- **Blur()**：移除某个元素焦点的方法。
- **FocusController**：管理某个面板的焦点状态与导航。
- **IFocusRing**：焦点导航逻辑所使用的接口。
- **FocusChangeDirection**：描述导航方向，例如 Next（下一个）、Previous（上一个）、Up（上）、Down（下）。



### 焦点工作流程

焦点系统的运作方式如下：

1. 用户输入可以通过两种方式触发焦点变化：一种是直接方式，通过指针交互（例如鼠标点击或触摸）；另一种是间接方式，通过触发导航事件（例如 Tab、Shift+Tab 或方向键），进而产生焦点事件。
2. `EventDispatcher`（事件分发器）处理输入，并在适当的时候请求 `FocusController` 改变焦点。
3. `FocusController` 咨询 `IFocusRing`，以确定下一个可聚焦的元素。
4. `FocusController` 生成焦点变化事件（例如 `FocusEvent` 和 `BlurEvent`），并把它们加入 `EventDispatcher` 的事件队列。`EventDispatcher` 在处理完当前用户输入之后，再分发这些事件。
5. `EventDispatcher` 分发焦点事件之后，新获得焦点的元素正式取得焦点。事件传播路径上的每个元素都可以在代码中通过事件回调来处理这些事件。
6. 如果某个元素的 `delegatesFocus = true`，焦点会自动交给某个可被聚焦的子元素。

### 元素的焦点顺序

每个面板都有一个焦点环（focus ring），它定义了元素的焦点顺序。默认情况下，对视觉树进行深度优先搜索（DFS）即可确定元素的焦点顺序。例如，下图所示那棵树的焦点顺序为 F、B、A、D、C、E、G、I、H。

> 焦点顺序

某些事件会使用焦点顺序来定义哪个元素持有焦点。例如，键盘事件的目标（target）就是当前处于焦点的元素。

你可以使用 `tabIndex` 属性来自定义焦点顺序，规则如下：

- 如果 `tabIndex` 为零，该元素保持其默认的 Tab 顺序，即由焦点环算法所决定的顺序。
- 如果 `tabIndex` 为正数，该元素会被排到其他 `tabIndex` 为零（`tabIndex = 0`）或 `tabIndex` 值小于它的元素前面。
- 如果 `tabIndex` 为负数，该元素会从 Tab 导航中被移除。



### 改变焦点

当元素获得或失去焦点时，就会发生焦点事件。你可以使用 `element.Focus()` 方法来改变焦点。该方法会发送一个 `FocusEvent`，该事件在事件队列中被处理。实际的焦点变化要等到当前事件回调执行完毕之后才会生效。

下面的示例让一个按钮获得焦点，并跟踪焦点事件：

```csharp
using UnityEngine;
using UnityEngine.UIElements;

[RequireComponent(typeof(UIDocument))]
public class FocusExample : MonoBehaviour
{
    void OnEnable()
    {
        var startGameButton = GetComponent<UIDocument>().rootVisualElement.Q<Button>("StartGame");

        startGameButton.RegisterCallback<FocusInEvent>(ev =>
        {
            Debug.Log("FocusInEvent: button is focused and can be activated with keyboard or gamepad input.");
        });

        Debug.Log("Calling startGameButton.Focus().");
        startGameButton.Focus();

        var isFocused = startGameButton.focusController.focusedElement == startGameButton;
        Debug.Log("Immediately after startGameButton.Focus(): isFocused=" + isFocused);

        // 预期输出：
        // > Calling startGameButton.Focus().
        // > FocusInEvent: button is focused and can be activated with keyboard or gamepad input.
        // > Immediately after startGameButton.Focus(): isFocused=true
    }
}
```

### 关键术语注释

1. **focus ring** → 焦点环：面板中定义焦点遍历顺序的环形结构，默认由视觉树的深度优先搜索决定。
2. **delegatesFocus** → 委托焦点：为 true 时，元素自身不保留焦点，而是转交给合适的子元素。
3. **canGrabFocus** → 可获取焦点：运行时条件判断（可见、启用等），与静态的 `focusable` 不同。
4. **FocusInEvent / FocusEvent / BlurEvent** → 焦点进入事件／焦点事件／失焦事件：均保留 API 原名，便于对照代码。
5. **DFS（depth-first search）** → 深度优先搜索：用于计算默认焦点顺序的遍历方式。
