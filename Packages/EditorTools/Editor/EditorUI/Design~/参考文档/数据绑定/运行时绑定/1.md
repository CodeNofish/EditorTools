# **运行时绑定入门**

通过一个示例学习运行时绑定的基础知识。 阅读时间：3 分钟 最后更新：14 天前 版本：6000.0+

想学习如何创建运行时数据绑定吗？用这个示例上手吧。该示例会创建一个数据源资源（asset），并在 UI Builder 中把这个数据源绑定到一个 UI 上。

要在 UI Builder 中设置运行时绑定，请执行以下操作：

1. 在 UI 控件的 **Inspector（检查器）** 面板中定义数据源和数据源路径。
2. 将 UI 控件的属性绑定到数据源资源的属性上。
3. 定义**绑定模式（Binding Mode）**，用于配置数据源与 UI 之间变更如何相互复制。
4. 定义**更新触发器（Update Trigger）**，用于配置数据源与 UI 之间变更在何时进行复制。



### 示例概览

本示例创建一个包含字符串属性的数据源资源，并在 UI Builder 中把它绑定到一个 `Label` 控件的 `Text` 属性上。当你在数据源资源中修改这个字符串属性时，标签的文本也会随之改变。

### 前置条件

本指南面向熟悉 Unity Editor、UI Toolkit 和 C# 脚本的开发者。开始之前，请先熟悉以下内容：

- UI Builder
- UXML



### 创建数据源资源

创建一个包含你想绑定的属性的数据源资源。在本示例中，你要创建一个名为 `ExampleObject` 的 `ScriptableObject` 资源，它包含一个字符串属性。

1. 用任意模板在 Unity 中创建一个项目。
2. 在项目的 Assets 文件夹中，创建一个名为 `ExampleObject.cs` 的 C# 脚本，内容如下：

```csharp
using Unity.Properties;
using UnityEngine;
using UnityEngine.UIElements;

#if UNITY_EDITOR
using UnityEditor;
#endif

[CreateAssetMenu]
public class ExampleObject : ScriptableObject
{
    [Header("Simple binding")]
    [CreateProperty]
    public string simpleLabel = "Hello World!";
}
```



### 创建示例对象资源

1. 从菜单中选择 **Assets > Create > Example Object**。这会在你项目的 Assets 文件夹中创建一个资源。
2. 将该资源重命名为 `ExampleObject.asset`。

### 创建 UI

创建一个 UI，用来绑定到上一步你创建的数据源资源。在本示例中，你要创建一个包含 `Label` 的 UXML 文件。

1. 在项目的 Assets 文件夹中，创建一个名为 `ExampleObject.uxml` 的 UXML 文件。
2. 双击 `ExampleObject.uxml` 文件，在 UI Builder 中打开它。
3. 在 **Hierarchy（层级）** 面板中，添加一个 `Label` 控件。

### 将 Label 绑定到数据源

把 UI 绑定到上一步你创建的数据源资源上。

1. 在 `Label` 的 **Inspector** 面板中，从 **Bindings > Data Source > Object** 列表中选择 `ExampleObject`。
2. 在 **Data Source Path（数据源路径）** 列表中，选择 `simpleLabel`。

> （设置 VisualElement 的绑定数据源）

1. 右键点击 `Text` 属性，选择 **Add binding（添加绑定）**。

> （添加绑定）

1. 从 **Binding Mode（绑定模式）** 列表中选择 **To Target**。这会在数据源发生变化时更新 UI。
2. 从 **Advanced Settings（高级设置） > Update Trigger（更新触发器）** 列表中，选择 **On Source Changed**（这是默认设置）。这会在数据源发生变化时更新 UI。

> （设置绑定模式和更新触发器）

1. 选择 **Add binding** 以应用你的更改。
2. 保存并关闭 UI Builder。你的 `ExampleObject.uxml` 文件看起来将如下所示：

```xml
<engine:UXML xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xmlns:engine="UnityEngine.UIElements" 
xmlns:editor="UnityEditor.UIElements" noNamespaceSchemaLocation="../../UIElementsSchema/UIElements.xsd" editor-extension-mode="False">
    <engine:Label text="Label" data-source="ExampleObject.asset" data-source-path="simpleLabel">
        <Bindings>
            <engine:DataBinding property="text" binding-mode="ToTarget" />
        </Bindings>
    </engine:Label>
</engine:UXML>
```

### 在 UI Builder 预览模式中测试绑定

在数据源资源中更新标签文本，并查看 UI 中是否已同步复制了这些更改。

1. 在项目的 Assets 文件夹中，选择 `ExampleObject.asset`。
2. 在 Inspector 窗口的 **Simple Label** 字段中输入文本。UI Builder 视口（Viewport）中 `Label` 的文本会显示你输入的文本。

**关键术语注释（运行时绑定）**

1. **runtime binding** → 运行时绑定：在播放/运行模式下把控件属性与数据源同步的绑定机制，区别于编辑器态的 SerializedObject 数据绑定。
2. **data source / data source path** → 数据源 / 数据源路径：数据源是提供数据的对象（本例为 `ScriptableObject` 资源），路径则指向其中的具体属性（如 `simpleLabel`）。
3. **binding mode** → 绑定模式：决定值在数据源与 UI 之间的复制方向，本文用的 `To Target` 表示"数据源 → UI"单向更新。
4. **update trigger** → 更新触发器：决定何时执行复制，`On Source Changed` 即数据源变化时触发。
5. **asset** → 资源：Unity 项目中磁盘上保存的对象文件（如 `.asset`、`.uxml`），与运行时的"对象（object）"相区别，故此处统一译作"资源"。

> 文中 UI Builder 菜单项与属性面板标签（如 Assets、Bindings、Add binding、To Target 等）按惯例保留英文，以便你在实际界面中对照查找。
