# 1. Create a custom control

**创建自定义控件** 了解创建和使用自定义控件的基础知识。

一个好的自定义控件应该是**抽象的、自包含的、可复用的**。

**滑动开关（Slide Toggle）** 就是一个很好的自定义控件示例：

- 它是**抽象的**。你可以用它来调节各种设置，比如音量、亮度、缩放比例和电源开关。
- 它是**自包含的**。你只需要给它一个标签和一个初始值，当它的状态改变时，它会触发一个事件。
- 它是**可复用的**。你可以在应用程序的多个地方使用它。

而**应用程序的菜单栏**就不是一个好的自定义控件示例：

- 它**不是抽象的**。它是特定于你的应用程序的。
- 它**不是自包含的**。它很可能依赖于应用程序的其他部分。
- 它**不是可复用的**。你的应用程序中可能只有一个菜单。

创建自定义控件后，你可以用 USS 来设置它的样式，并用 C# 添加逻辑来处理事件。



### 创建和使用自定义控件

要创建自定义控件，请执行以下操作：

1. 在自定义控件类定义上添加 `UxmlElement` 特性。
2. 将自定义控件类声明为 `partial`（部分）类。
3. 让它继承自 `VisualElement` 或其派生类之一。

例如：

```csharp
using UnityEngine;
using UnityEngine.UIElements;

[UxmlElement]
public partial class ExampleElement : VisualElement {}
```

创建自定义控件后，你就可以在 UXML 和 UI Builder 中使用它们了。以下示例 UXML 文档使用了该自定义控件：

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements">
    <ExampleElement />
</ui:UXML>
```

默认情况下，自定义控件会出现在 UI Builder 的 **Library（库）** 选项卡中。如果你想把它从库选项卡中隐藏，可以添加 `HideInInspector` 特性。



### 初始化自定义控件

自定义控件继承自 `VisualElement`。`VisualElement` 不是 `MonoBehaviour`，因此不会接收 `MonoBehaviour` 的任何回调，比如 `Awake()`、`OnEnable()`、`OnDisable()` 和 `OnDestroy()`。

你可以在自定义控件的**构造函数**中对其进行初始化。不过，如果你的应用程序需要，你也可以将初始化延迟到自定义控件被添加到 UI 时再进行。要做到这一点，可以注册一个 `AttachToPanelEvent` 的回调。要检测自定义控件是否已从 UI 中移除，可以使用 `DetachFromPanelEvent` 回调。

```csharp
public CustomControl()
{
    RegisterCallback<AttachToPanelEvent>(e =>
        { /* 当元素被添加到 UI 时在此执行操作 */ });
    RegisterCallback<DetachFromPanelEvent>(e =>
        { /* 当元素从 UI 中移除时在此执行操作 */ });
}
```

UI Toolkit 会为所有元素分发这两个事件，不需要自定义的 `VisualElement` 子类。更多信息请参考 **Panel events（面板事件）**。



### 用 USS 设置自定义控件的样式

使用 USS 自定义自定义控件的外观，方式与内置控件相同。你也可以创建 USS 自定义属性来设置自定义控件的样式。

> **注意**：UI Builder 中的 Inspector 窗口不会显示 USS 自定义属性。要编辑 USS 自定义属性，请使用文本编辑器直接编辑你的 USS 文件。

要在 C# 中与自定义控件的自定义 USS 属性交互，请使用 `CustomStyleProperty` 结构和 `CustomStylesResolvedEvent` 事件。

`CustomStyleProperty` 描述了你从样式表中读取的属性的名称和类型。

UI Toolkit 会为任何直接接收自定义 USS 属性的元素分发 `CustomStylesResolvedEvent` 事件。对于选择器匹配到的任何元素，只要该选择器的规则包含自定义属性的值，就会分发该事件。UI Toolkit **不会**为继承该值的元素分发此事件。该事件持有一个 `ICustomStyle` 对象的引用。你必须使用它的 `TryGetValue()` 方法来读取 `CustomStyleProperty` 的有效值。该方法针对不同类型的 `CustomStyleProperty` 提供了多个重载。

关于自定义控件的自定义样式示例，请参考 **Create custom style for a custom control**。

> **注意**：你无法为自定义样式属性定义过渡效果（transitions）。



### 处理自定义控件的事件

有关如何处理自定义控件事件的详细信息，请参考 **Handle events（处理事件）**。

> **注意**：Unity 会将键盘事件分派给当前获得焦点的元素。要处理自定义控件的键盘事件，请设置与焦点相关的属性。

要处理触摸和鼠标输入事件，请在构造函数中注册相关事件类型的回调，比如指针事件（pointer events）和鼠标事件（mouse events）。



### 最佳实践与技巧

- 将自定义控件所代表的属性及其行为的其他功能方面作为 **UXML 属性**公开，将影响自定义控件外观的属性作为 **USS 属性**公开。
- 使用**唯一、简短且可读**的命名空间，以避免与其他元素发生命名冲突。
- 保持 UXML 属性为**基本类型**。你可以在 UXML 中指定的数据仅限于一组基本数据类型。UXML 不支持复杂的数据结构或集合。请通过 C# 脚本或数据绑定在运行时将复杂数据传递给自定义控件，而不是在 UXML 中传递。
- 在 C# 中，将 USS 类名或名称作为**常量**公开。这样你就可以使用 UQuery 按类或名称定位元素。
- 采用 **BEM 标准**来命名 USS 类。这让你可以使用类列表选择器来定位每个元素。
- 使用**静态回调**以降低内存占用。当你注册一个实例方法作为回调时，可能会产生不必要的内存分配。为避免分配，请使用调用常规 C# 静态方法的匿名静态 lambda 函数。你可以通过 `EventBase.currentTarget` 属性获取当前元素的上下文。
- 通过自定义控件的 `generateVisualContent` 回调来渲染自定义几何图形。关于渲染部分填充圆形的示例用法，请参考 **RadialProgress 示例**。

自定义控件很方便。不过，你也可以通过以下方式实现相同的效果：

- 用现有元素组装你的 UI，并更改它们的样式和属性。
- 使用 UXML 模板。使用常规的 C# `MonoBehaviour` 来添加与持有 UI 的 UI Document 相关的逻辑。要了解如何使用 `MonoBehaviour` 来控制 UI Document 中的 UI，请参考 **Create your first runtime UI**。为了实现封装，可以在 `MonoBehaviour` 中创建属性和方法，在内部使用 UQuery 获取 `VisualElement` 并操作它们的属性。
