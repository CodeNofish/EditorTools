# Configure the custom control name and visibility in UI Builder

**在 UI Builder 中配置自定义控件的名称与可见性**

使用 `UxmlElement` 特性来更改自定义控件在 UXML 和 UI Builder 库中的显示方式。 



### 自定义 UXML 标签名称

默认情况下，自定义控件在 UXML 中的标签名称就是 C# 类名。虽然不建议使用不同的标签名称，但你可以在需要时进行自定义。

要自定义 UXML 标签名称，请在 `UxmlElement` 特性中添加一个 `name` 参数。

> **注意**：标签名称必须唯一，并且你必须在 UXML 中引用该类所在的命名空间。

例如，如果你创建以下自定义按钮：

```csharp
using UnityEngine.UIElements;

namespace MyNamespace
{
    [UxmlElement("MyButton")]
    public partial class CustomButtonElement : Button
    {
    }
}
```

然后你就可以在 UXML 中使用自定义名称或 C# 类名来引用该自定义按钮：

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements">
    <MyNamespace.MyButton />
    <MyNamespace.CustomButtonElement />
</ui:UXML>
```



### 配置路径和可见性

默认情况下，自定义控件会出现在 UI Builder 库中与其 C# 命名空间对应的路径下。你可以使用 `libraryPath` 参数来自定义 `UxmlElement` 特性的路径。

默认情况下，以 `Unity`、`UnityEngine` 或 `UnityEditor` 开头的命名空间是保留的，因此这些命名空间中的元素不会出现在 UI Builder 库中。 你可以使用 `visibility` 参数来覆盖这一行为，使你的控件可见。

以下示例展示了如何让一个自定义控件以自定义路径显示在 UI Builder 库中，以及如何隐藏另一个自定义控件：

```csharp
using UnityEngine.UIElements;

namespace Unity.MyGame
{
    // 此元素在 UI Builder 库的 "My Game/Inventory" 路径下可见。
    [UxmlElement(libraryPath = "My Game/Inventory", visibility = LibraryVisibility.Visible)]
    public partial class VisibleItem : VisualElement
    {
        [UxmlAttribute]
        public string description { get; set; }
    }
}

// 此元素在 UI Builder 库中隐藏。
// 但你仍然可以在 UXML 或 C# 代码中使用它。
[UxmlElement(visibility = LibraryVisibility.Hidden)]
public partial class HiddenItem : VisualElement
{
    [UxmlAttribute]
    public string description { get; set; }
}
```
