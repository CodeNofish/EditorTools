# **为复杂数据类型定义自定义控件属性**

使用属性转换器（Attribute Converter）和 `UxmlObject` 来为复杂数据类型定义 UXML 属性。 

你可以使用属性转换器和 `UxmlObject` 来支持自定义控件的复杂数据类型属性。



### 属性转换器（Attribute Converters）

属性转换器负责将 `UxmlAttribute` 类型与字符串之间进行相互转换。Unity 为常见类型（如 `int`、`float`、`bool`、`string` 和 `Vector2`）提供了一组内置转换器。但对于列表或自定义类等复杂数据类型，你需要创建自定义转换器。

以下 C# 代码示例创建了一个名为 `Person` 的自定义类和一个名为 `Department` 的自定义控件类。`Department` 类包含一个用于表示经理的 `Person` 字段，以及一个用于表示员工的 `Person` 对象列表。

```csharp
using System;
using System.Collections.Generic;
using UnityEngine.UIElements;

namespace AttributeConverterExample
{
    [Serializable]
    public class Person
    {
        public string name;
        public int age;
        public string nationality;
    }

    [UxmlElement]
    public partial class Department : VisualElement
    {
        [UxmlAttribute]
        public Person manager;

        [UxmlAttribute]
        public List<Person> employees;
    }
}
```

如果你在 UI Builder 中编辑该自定义控件，会收到以下错误信息： `[UxmlElement] 'Department' has a [UxmlAttribute] 'manager' of an unknown type 'Person'. To fix this error, define a custom UxmlAttributeConverter<Person>.`

为了解决这个问题，你需要为 `Person` 类创建一个继承自 `UxmlAttributeConverter<Person>` 的属性转换器，并实现 `ToString` 和 `FromString` 方法，以便将 `Person` 对象与字符串之间进行转换。以下示例为 `Person` 类创建了一个转换器：

```csharp
using UnityEditor.UIElements;

namespace AttributeConverterExample
{
    public class PersonConverter : UxmlAttributeConverter<Person>
    {
        const char k_Separator = ':';

        public override string ToString(Person value)
        {
            return $"{value.name}{k_Separator}{value.age}{k_Separator}{value.nationality}";
        }

        public override Person FromString(string value)
        {
            var person = new Person();
            var split = value.Split(k_Separator);
            if (split.Length == 3)
            {
                person.name = split[0];
                person.age = int.Parse(split[1]);
                person.nationality = split[2];
            }
            return person;
        }
    }
}
```

该转换器将三个值合并为一种单一的字符串格式，模式为 `[name]:[age]:[nationality]`。`FromString` 方法将字符串拆分为三个值，并将它们分配给 `Person` 对象。

以下展示了在 UXML 文件中使用 `Department` 元素的示例：

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements">
    <AttributeConverterExample.Department name="Dunder Mifflin" manager="Michael Scott:58:USA" employees="Dwight Schrute:53:USA,Jim Halpert:44:USA" />
</ui:UXML>
```



### UxmlObjects

在使用属性转换器时，随着数据类型变得更加复杂或处理大型列表，生成的字符串会迅速变得复杂且难以处理。为了简化这一问题，你可以使用 `UxmlObjects`。

`UxmlObjects` 是从 UXML 实例化的类，其中包含 UXML 属性。

要了解如何使用 `UxmlObjects`，以上述 `Person` 和 `Department` 类为例，将它们转换为 `UxmlObjects`，如下所示：

```csharp
using System;
using System.Collections.Generic;
using UnityEngine.UIElements;

namespace UxmlObjectExample
{
    [UxmlObject]
    public partial class Person
    {
        [UxmlAttribute]
        public string name;

        [UxmlAttribute]
        public int age;

        [UxmlAttribute]
        public string nationality;
    }

    [UxmlElement]
    public partial class Department : VisualElement
    {
        [UxmlObjectReference("manager")]
        public Person manager;

        [UxmlObjectReference("employees")]
        public List<Person> employees;
    }
}
```

现在 `Person` 类类似于一个自定义元素，它使用 `UxmlAttribute` 进行属性声明，并引入 `UxmlObject` 特性来表明其作为 `UxmlObject` 的身份。

对于 `UxmlObject` 字段，此示例使用 `UxmlObjectReference` 来分配名称，而不是使用 `UxmlAttribute`。该名称指定了 `UxmlObject` 的父元素。

以前，所有 `UxmlObjects` 都存储为元素的直接子级，当存在多个 `UxmlObject` 字段时，这会导致可扩展性问题，因为很难区分哪些 `UxmlObjects` 属于哪个字段。

`UxmlObjectReference` 特性通过为 `UxmlObject` 指定名称解决了这一问题。该名称对应于 UXML 标签名称。在上述示例中，`manager` 和 `employees` 字段属于 `Person` 类。`UxmlObjectReference` 特性确保 `Person` 类被正确分配给 `manager` 和 `employees` 字段。

以下展示了在 UXML 文件中的使用示例：

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements">
    <UxmlObjectExample.Department name="Department One">
        <manager>
            <UxmlObjectExample.Person name="Manager One" age="58" nationality="Canadian" />
        </manager>
        <employees>
            <UxmlObjectExample.Person name="Person Two" age="53" nationality="Canadian" />
            <UxmlObjectExample.Person name="Person Three" age="44" nationality="Canadian" />
        </employees>
    </UxmlObjectExample.Department>
</ui:UXML>
```

> **注意**：`UxmlObjectReferenceFields` 也适用于接口。但是，你只能分配实现了指定接口的 `UxmlObjects`。有关使用接口的示例，请参考 `UxmlObjectReferenceAttribute`。
