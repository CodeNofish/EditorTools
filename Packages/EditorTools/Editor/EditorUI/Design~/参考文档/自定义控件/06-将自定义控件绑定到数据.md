# **将自定义控件绑定到数据**

将自定义控件绑定到序列化属性，以同步控件与属性之间的值。 阅读时间：1 分钟 最后更新：14 天前

你可以将自定义控件绑定到序列化属性，以同步控件与属性之间的值。

你可以创建一个派生自泛型基类 `BaseField` 而非 `BindableElement` 的可绑定自定义控件。这样做具有以下优势：

- 为你指定的泛型参数类型实现 `INotifyValueChanged` 接口。
- 默认使控件可获得焦点。
- 提供水平布局，左侧为标签元素，右侧为输入元素。

`FloatField` 是一个内置的 UI Toolkit 控件，它继承自 `BaseField`。A. 标签元素。B. 输入元素。



> **注意**：如果你了解内置 UI 控件的内部层级结构和现有的 USS 类，确实可以基于它们创建自定义控件。但 Unity 不鼓励这种做法，因为你的自定义控件可能会依赖于其内部结构，而这些结构在未来可能会发生变化。

要将自定义控件绑定到数据：

1. 实现 `INotifyValueChanged` 接口，并根据需要监听 `ChangeEvents`。
2. 继承自 `BindableElement` 类或实现 `IBindable` 接口。
3. 更多细节请参考 **SerializedObject 数据绑定**。

有关可绑定自定义控件的示例，请参考 **创建可绑定的自定义控件**。
