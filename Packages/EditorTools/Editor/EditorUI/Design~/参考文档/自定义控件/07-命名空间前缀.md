# **定义命名空间前缀**

使用 `UxmlNamespacePrefix` 特性来定义命名空间前缀。 阅读时间：1 分钟 最后更新：2 个月前

在定义了自定义控件元素后，你可以在 UXML 文件中使用它。为了对元素进行分类，可以在命名空间中创建类。当你定义一个新的命名空间时，可以为该命名空间定义一个前缀。你必须将命名空间前缀定义为根 `<UXML>` 元素的属性，并在限定元素范围时替换完整的命名空间名称。

要定义命名空间前缀，请为每个命名空间前缀向你的程序集添加一个 `UxmlNamespacePrefix` 特性。例如：

```csharp
[assembly: UxmlNamespacePrefix("My.First.Namespace", "first")]
[assembly: UxmlNamespacePrefix("My.Second.Namespace", "second")]
```

你可以在程序集的任何 C# 文件的根级别（任何命名空间之外）执行此操作。

架构生成系统会执行以下操作：

1. 检查这些特性并使用它们来生成架构。
2. 将命名空间前缀定义作为属性添加到新创建的 UXML 文件的 `<UXML>` 元素中。
3. 在其 `xsi:schemaLocation` 属性中包含该命名空间的架构文件位置。

为了确保你的文本编辑器能识别新元素，请选择 **Assets > Update UXML Schema** 来更新架构定义。

要创建带有前缀的新 UXML 文档，请选择 **Assets > Create > UI Toolkit > UI Document (UXML)**。
