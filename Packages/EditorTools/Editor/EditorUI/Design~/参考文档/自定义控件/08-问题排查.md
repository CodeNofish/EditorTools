# **排查自定义控件库编译问题**

排查自定义控件库编译时遇到的问题。 阅读时间：1 分钟 最后更新：14 天前

本故障排除指南可帮助你解决将自定义控件编译为 DLL 时遇到的问题。

### 症状

当将自定义控件编译为 DLL 时，你可能会遇到以下问题：

- 自定义控件未出现在 UI Builder 中。
- 在构建库 (DLL) 时，自定义控件无法正确序列化。

### 原因

UI Toolkit 使用 `UxmlElement` 代码生成器来支持 UXML 序列化。然而，当将自定义控件编译为 DLL 时，默认情况下不会包含生成的序列化代码，从而导致元素可见性和序列化出现问题。

### 解决方案

要解决此问题，请在 DLL 编译过程中运行 UI Toolkit 源代码生成器 (`Unity.UIToolkit.SourceGenerator.dll`)。

1. 在你的 Unity 安装目录中查找源代码生成器文件。它通常位于：`<Unity 安装路径>\Data\Tools\Unity.SourceGenerators\Unity.UIToolkit.SourceGenerator.dll`。
2. 将源代码生成器作为分析器添加到库项目的 `.csproj` 文件中的 `<ItemGroup>` 内：

```xml
<ItemGroup>
    <Analyzer Include="path\to\Unity.UIToolkit.SourceGenerator.dll" />
</ItemGroup>
```

1. 照常编译你的库。这将触发源代码生成器，为你的自定义控件生成所需的 `UxmlSerializedData` 类。

> **提示**：始终针对你正在使用的 Unity 版本重新构建你的库，因为生成的代码可能会因版本而异。
