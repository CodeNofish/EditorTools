# **为自定义控件创建自定义样式**

创建一个自定义控件，从 USS 中读取两种颜色，并用它们生成一张纹理。 阅读时间：2 分钟 最后更新：14 天前 版本：2023.2+

本示例演示如何在自定义控件中使用自定义 USS 变量。



### 示例概览

本示例创建一个自定义控件，该控件从 USS 中读取两种颜色，并使用它们生成一张纹理。

> （一张红黄渐变色的示例纹理。）

本示例最终创建的完整成品文件，可在该 GitHub 仓库中找到。



### 创建自定义控件

创建一个 C# 脚本来定义自定义控件，并创建一个 USS 文件来定义自定义样式。

1. 使用任意模板创建一个 Unity 项目。
2. 创建一个名为 `create-custom-style-custom-control` 的文件夹，用于存放你的文件。
3. 在 `ExampleElementCustomStyle` 文件夹中，创建一个名为 `ExampleElementCustomStyle.cs` 的 C# 脚本，并将其内容替换为以下代码：

```csharp
using UnityEngine;
using UnityEngine.UIElements;

namespace UIToolkitExamples
{
    [UxmlElement]
    public partial class ExampleElementCustomStyle : VisualElement
    {
        // 使用 CustomStyleProperty<T> 从 USS 获取自定义样式属性
        static readonly CustomStyleProperty<Color> S_GradientFrom = new CustomStyleProperty<Color>("--gradient-from");
        static readonly CustomStyleProperty<Color> S_GradientTo = new CustomStyleProperty<Color>("--gradient-to");

        // 子 Image 元素及其纹理
        Texture2D m_Texture2D;
        Image m_Image;

        public ExampleElementCustomStyle()
        {
            // 创建一个 Image 及其纹理。将 Image 附加到自身。
            m_Texture2D = new Texture2D(100, 100);
            m_Image = new Image();
            m_Image.image = m_Texture2D;
            Add(m_Image);

            RegisterCallback<CustomStyleResolvedEvent>(OnStylesResolved);
        }

        // 当此控件的自定义样式已解析时，根据颜色生成渐变。
        void OnStylesResolved(CustomStyleResolvedEvent evt)
        {
            Color from, to;

            if (evt.customStyle.TryGetValue(S_GradientFrom, out from)
                && evt.customStyle.TryGetValue(S_GradientTo, out to))
            {
                GenerateGradient(from, to);
            }
        }

        public void GenerateGradient(Color from, Color to)
        {
            for (int i = 0; i < m_Texture2D.width; ++i)
            {
                Color color = Color.Lerp(from, to, i / (float)m_Texture2D.width);
                for (int j = 0; j < m_Texture2D.height; ++j)
                {
                    m_Texture2D.SetPixel(i, j, color);
                }
            }

            m_Texture2D.Apply();
            m_Image.MarkDirtyRepaint();
        }
    }
}
```



### 创建自定义控件和自定义样式

创建一个名为 `ExampleElementCustomStyle.uss` 的 USS 文件，并将其内容替换为以下代码：

```css
ExampleElementCustomStyle {
	--gradient-from: red;
	--gradient-to: yellow;
}
```



### 在 UI 文档中使用自定义控件

创建一个 UI 文档以使用自定义控件，并将自定义样式应用到该自定义控件上。

1. 在 `ExampleElementCustomStyle` 文件夹中，创建一个名为 `ExampleElementCustomStyle.uxml` 的 UI 文档。
2. 双击 `ExampleElementCustomStyle.uxml` 在 UI Builder 中打开它。
3. 选择 **Library > Project > UIToolkitExamples**，然后将 `ExampleElementCustomStyle` 拖拽到 **Hierarchy（层级）** 窗口中。视口（Viewport）窗口中会出现一个灰色方块。
4. 将 `ExampleElementCustomStyle.uss` 文件作为现有 USS 添加。这会将自定义 USS 变量应用到该方块上。
