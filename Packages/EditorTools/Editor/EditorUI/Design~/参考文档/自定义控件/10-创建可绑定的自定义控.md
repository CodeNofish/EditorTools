# **创建可绑定的自定义控件**

创建一个绑定到 `double` 数据类型属性的自定义控件。

本示例演示如何在自定义编辑器窗口中创建一个可绑定的自定义控件。



### 示例概览

本示例创建一个绑定到 `double` 数据类型属性的自定义控件。你可以调整此示例，使其绑定到其他数据类型的属性，例如字符串或整数。

> （Unity 编辑器中包含一个自定义控件的脚本。）

本示例最终创建的完整成品文件，可在该 GitHub 仓库中找到。



### 创建自定义控件类

创建一个 C# 类来定义自定义控件。

1. 使用任意模板创建一个 Unity 项目。
2. 创建一个名为 `ExampleField` 的文件夹，用于存放你的文件。
3. 在 `ExampleField` 文件夹中，创建一个名为 `ExampleField.cs` 的 C# 脚本，并将其内容替换为以下代码：

```csharp
using UnityEngine.UIElements;

namespace UIToolkitExamples
{
    // ExampleField 继承自 BaseField<double>，因此 ExampleField 的底层值类型为 double。
    [UxmlElement]
    public partial class ExampleField : BaseField<double>
    {
        Label m_Input;

        // 默认构造函数，用于与 UXML 工厂兼容
        public ExampleField() : this(null)
        {

        }

        // 主构造函数接受 label 参数，以模仿 BaseField 的构造函数。
        // 传给 base 构造函数的第二个参数是输入元素，即显示该字段所绑定值的元素。
        public ExampleField(string label) : base(label, new Label() { })
        {
            // 这是为 base 构造函数实例化的输入元素。
            m_Input = this.Q<Label>(className: inputUssClassName);
        }

        // 需要重写 SetValueWithoutNotify：先调用 base 版本，然后让底层值的变化反映到输入元素上。
        public override void SetValueWithoutNotify(double newValue)
        {
            base.SetValueWithoutNotify(newValue);

            m_Input.text = value.ToString("N");
        }
    }
}
```



### 在 UXML 文件中使用自定义控件

1. 在 `ExampleField` 文件夹中，创建一个名为 `ExampleField.uxml` 的 UI 文档。
2. 用文本编辑器打开 `ExampleField.uxml`，并将其内容替换为以下代码：

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements" xmlns:example="UIToolkitExamples">
    <example:ExampleField label="Binding Target" binding-path="m_Value" />
</ui:UXML>
```



### 创建绑定目标类

1. 在 Unity 中，双击 `ExampleField.uxml` 在 UI Builder 中打开它。`ExampleField` 会显示在 **Hierarchy（层级）** 窗口中，并在视口（Viewport）中可视化。如果你在层级窗口中选择 `ExampleField`，**Inspector（检查器）** 窗口会显示分配给 **Binding Path（绑定路径）** 和 **Label（标签）** 框的值。
2. 在 `ExampleField` 文件夹中，创建一个名为 `ExampleFieldComponent.cs` 的 C# 脚本，并将其内容替换为以下代码：

```csharp
using UnityEngine;

namespace UIToolkitExamples
{
    public class ExampleFieldComponent : MonoBehaviour
    {
        [SerializeField]
        double m_Value;
    }
}
```

### 为绑定目标创建自定义编辑器

1. 在 `ExampleField` 文件夹中，创建一个名为 `Editor` 的文件夹。
2. 在 `Editor` 文件夹中，创建一个名为 `ExampleFieldCustomEditor.cs` 的 C# 脚本，并将其内容替换为以下代码：

```csharp
using UnityEditor;
using UnityEngine.UIElements;
using UnityEngine;

namespace UIToolkitExamples
{
    [CustomEditor(typeof(ExampleFieldComponent))]
    public class ExampleFieldCustomEditor : Editor
    {
        [SerializeField]
        VisualTreeAsset m_Uxml;

        public override VisualElement CreateInspectorGUI()
        {
            var parent = new VisualElement();

            m_Uxml?.CloneTree(parent);

            return parent;
        }
    }
}
```

### 测试示例

1. 在 Unity 中，于 **Project（项目）** 窗口选择 `ExampleFieldCustomEditor.cs`。
2. 将 `ExampleField.uxml` 拖拽到 Inspector 窗口的 **Uxml** 框中。
3. 向场景中添加一个空的 GameObject。
4. 将 `ExampleFieldComponent` 组件添加到该 GameObject 上。自定义控件会出现在 Inspector 中，**Binding Target** 的默认值为 0。如果你更改底层 `double` 属性的值，UI 会反映出该变化。
