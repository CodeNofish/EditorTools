按 Editor 工具库定位，建议先按 **8 个大类**组织：**输入与字段、选择器、列表与表格、导航与布局、状态与反馈、数据与配置、调试与诊断、窗口与面板骨架**。这样既能覆盖 EditorWindow、Inspector、ScriptableObject 编辑器、批量工具、资源管线等常见场景，也方便你后续按 asmdef 模块拆分。

### 1. 输入与字段类

| 组件 | 用途 |
|---|---|
| LabeledField | Label + 输入控件 + 校验提示统一容器 |
| ValidatedField | 带校验规则、错误状态、修复建议的输入框 |
| NumberField | int/float/double 统一数值输入 |
| RangeField | 带 clamp、snap、步长控制的数值调节 |
| MinMaxRangeField | 区间选择，适合 LOD、时间轴、阈值配置 |
| Vector2/3/4Field | 坐标、缩放、法线、颜色分量输入 |
| CurveField | AnimationCurve 编辑 |
| GradientField | 渐变配置 |
| TagField / LayerField | Tag、Layer 快速选择 |
| PathField | 资产/文件夹路径输入，支持浏览按钮 |
| SearchField | 轻量搜索框，配合列表/树使用 |
| ColorPickerField | 颜色选择 + 最近颜色记录 |
| EnumFlagsField | 多选型枚举输入 |
| MaskField | 层级/通道/分类掩码选择 |
| TextFieldWithHistory | 带历史下拉的文本输入 |

### 架构与发布建议

- **核心层**：`UIElements` 通用控件，不依赖 `UnityEditor`。
- **Editor 层**：`UnityEditor.UIElements` 专用控件，如 `PropertyField`、`Toolbar`、`ObjectField`。
- **业务复合层**：Wizard、BatchTool、AssetPipeline 等高层面板。
- **样式层**：提供 `Theme`、`IconProvider`、`USS Variables`，统一 Light/Dark 主题。
- **发布层**：按模块拆成独立 asmdef 和 Package，例如 `EditorUI.Core`、`EditorUI.Controls`、`EditorUI.Panels`、`EditorUI.Diagnostics`。

如果要做 100+ 组件，建议先实现 **输入字段 16 + 选择器 10 + 列表表格 10 + 导航布局 12 + 状态反馈 12 + 数据配置 10 + 调试诊断 10 + 窗口面板 12**，大约 92 个基础组件，再根据实际工具场景补到 120 个左右会更稳。
