做 Editor 工具包时，Manipulator 很适合做成**独立、可复用、可组合**的交互能力模块。UI Toolkit 内置提供的基类主要有：`Manipulator`、`MouseManipulator`、`PointerManipulator`、`Clickable`、`ContextualMenuManipulator`、`KeyboardNavigationManipulator`。

下面按“编辑器工具常用场景”整理一套值得设计的 Manipulator。

### 1. 点击与手势类

| Manipulator | 适用场景 | 设计要点 |
|---|---|---|
| **Clickable 增强版** | 按钮、卡片、列表项、工具面板 | 内置 `Clickable` 只处理“按下+抬起在同一元素”的点击；你可以扩展成单击、双击、长按、右键点击、修饰键组合。 |
| **Draggable / Reorderable** | 列表排序、节点拖拽、Inspector 条目重排 | 基于 `PointerManipulator`，处理 `PointerDown/Move/Up/CaptureOut`，支持拖拽阈值、吸附、占位符。 |
| **DragThresholdFilter** | 区分“点击”和“拖拽” | 很多 Editor 控件既要点击又要拖拽，建议单独抽一个阈值判断器。 |
| **MultiTouch / Pinch** | 节点图缩放、预览窗口缩放 | 编辑器里不常用，但如果做 Scene/Graph 类工具会很有价值。 |

### 2. 尺寸、布局与停靠类

| Manipulator | 适用场景 | 设计要点 |
|---|---|---|
| **Resizable** | 面板分割线、窗口边缘拖拽 | 支持水平/垂直/四角拖拽，最好暴露最小/最大尺寸。 |
| **Dockable / Snappable** | 多面板停靠、工具窗口吸附 | 拖拽时显示吸附预览区域，释放后触发布局变更事件。 |
| **ColumnResizer** | ListView / TableView 表头 | 拖拽列宽时只影响相邻列，支持双击自适应。 |
| **Splitter** | 左右/上下分栏 | 适合做 Editor 工具的主布局，比直接写死 USS 更灵活。 |

### 3. 选择、聚焦与导航类

| Manipulator | 适用场景 | 设计要点 |
|---|---|---|
| **Selectable** | 列表项、节点、资源卡片 | 支持单选、多选、Shift 连续选择、Ctrl 切换选择。 |
| **FocusRing / TabNavigation** | 表单、属性面板、快捷键工具 | 基于 `KeyboardNavigationManipulator`，统一处理 Tab/Shift+Tab/方向键。 |
| **HighlightOnHover** | 可交互区域提示 | 悬停时加 USS class，离开时移除，适合做按钮、卡片、工具栏项。 |
| **Tooltip** | 图标按钮、状态指示器 | 悬停延迟显示，离开隐藏；支持富文本或自定义 USS。 |

### 4. 右键菜单与快捷操作类

| Manipulator | 适用场景 | 设计要点 |
|---|---|---|
| **ContextualMenuManipulator** | 列表项、节点、资源卡片 | 内置 Manipulator，右键或菜单键触发；适合做“重命名/删除/复制/属性”。 |
| **QuickActionStrip** | 悬停显示快捷按钮 | 类似 Inspector 中某些字段右侧的小按钮，适合做复制、锁定、刷新。 |
| **InlineEditManipulator** | 标签双击变输入框 | 双击 Label 切换成 TextField，保存后切回；适合做节点名、资源名编辑。 |

### 5. 滚动、缩放与画布类

| Manipulator | 适用场景 | 设计要点 |
|---|---|---|
| **CanvasPanner** | 节点图、地图、大图预览 | 按住中键或空格拖拽画布，支持惯性滚动。 |
| **CanvasZoomer** | 节点图缩放 | 滚轮缩放，最好支持以鼠标位置为中心缩放。 |
| **ScrollSync** | 多列表同步滚动 | 适合对比视图、双栏日志、左右属性表。 |

### 6. 输入与表单增强类

| Manipulator | 适用场景 | 设计要点 |
|---|---|---|
| **AutoComplete** | 搜索框、资源选择器 | 输入时弹出候选列表，支持键盘上下选择。 |
| **NumericStepper** | 数值字段增强 | 鼠标拖拽增减数值，类似 Inspector 中部分字段的行为。 |
| **ColorPickerTrigger** | 颜色字段 | 点击弹出颜色选择浮层，适合做自定义属性面板。 |
| **ValidationFeedback** | 表单输入校验 | 输入非法时显示红色边框、Tooltip 或内联提示。 |

### 7. 调试与开发辅助类

| Manipulator | 适用场景 | 设计要点 |
|---|---|---|
| **LayoutDebugOverlay** | 调试 USS 布局 | 悬停或快捷键显示元素边界、padding、margin。 |
| **EventLogManipulator** | 调试交互问题 | 记录 Pointer/Keyboard/Mouse 事件，适合排查捕获、冒泡问题。 |
| **PerformanceOverlay** | 面板性能监控 | 显示当前面板元素数量、重绘次数、事件耗时。 |

### 推荐优先实现的最小集合

如果你这套库要尽快可用，建议先做这 8 个：

1. **EnhancedClickable**：单击、双击、长按、右键。
2. **Draggable**：基础拖拽。
3. **ReorderableList**：列表项重排。
4. **Resizable**：面板/列宽拖拽。
5. **Selectable**：单选/多选。
6. **ContextualMenuManipulator 封装**：统一右键菜单接口。
7. **Tooltip**：悬停提示。
8. **CanvasPanner + CanvasZoomer**：节点图/预览画布常用。

实现上建议统一继承 `PointerManipulator` 或 `MouseManipulator`，在构造函数里配置 `activators`，并重写 `RegisterCallbacksOnTarget` / `UnregisterCallbacksFromTarget`。这样你的组件库会更容易扩展，也不会把事件逻辑散落在每个 `VisualElement` 里。

## 已落地的基础操纵器

代码位于 `Manipulators/`，命名空间 `EditorUI.Manipulators`，统一用 `AddManipulator` 挂载，USS class 统一使用 `editorui-` 前缀。

| 文件 | 作用 |
|---|---|
| `PointerDragManipulator.cs` | 拖拽类基类：激活器、拖拽阈值、指针捕获、中断清理与事件参数 |
| `Draggable.cs` | 基础拖拽，支持轴向限制、吸附、自定义位移 |
| `Resizable.cs` | 四边 / 四角调整尺寸，支持最小、最大尺寸 |
| `EnhancedClickable.cs` | 单击、双击、长按、右键；用位移阈值区分点击与拖拽，不抢占指针捕获 |
| `SelectionManipulator.cs` | 容器级单选、Ctrl/Cmd 切换、Shift 连续选择 |
| `ContextMenuManipulator.cs` | 内置右键菜单的条目化封装，支持动态增删与禁用状态 |
| `TooltipManipulator.cs` | 延迟显示的提示浮层，可自定义 USS class |
| `CanvasPanner.cs` / `CanvasZoomer.cs` | 中键（可选左键）平移、滚轮以指针为锚点缩放 |

最小集合里的 `ReorderableList` 依赖占位符与数据源，属于列表控件层，不在操纵器层实现。
